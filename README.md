# looplish
A tool for breaking down a video / audio into sentences to listen to.

## Contributing

Non-draft pull requests into `main` from branches in this repository are reviewed
automatically by an AI reviewer (draft PRs and PRs from forks are not). See
[`.github/ai-review/README.md`](.github/ai-review/README.md) (in Chinese) for how the
review works and when a PR is merged automatically.
